# AI 陪练平台 产品需求文档（PRD v1.0）

> 文档状态：初稿｜最后更新：2026-09-22｜维护：AI 陪练项目组
> 适用范围：公主购 AI 陪练双端（小程序 C 端学员 + Web B 端运营）

---

## 1. 背景与目标

### 1.1 业务背景
神首集团/公主购体系下，私域导购/主播需要通过话术完成客户破冰、需求挖掘、产品推荐、异议处理、逼单成交。传统培训依赖真人 role-play，成本高、不可复制、难以规模化考核。

### 1.2 产品定位
一个 **AI 销售陪练平台**：学员在小程序里与 AI 扮演的"虚拟客户"对话，AI 模拟真实客户的画像、情绪、疑虑，结束后由 AI 教练给出结构化评分和改进建议；运营人员在 Web 端配置客户模板、评分规则、发布训练任务、查看学员成长档案。

### 1.3 核心目标
| 目标 | 衡量指标 |
|---|---|
| 让新人快速上手私域话术 | 独立完成 1 场完整陪练的时长、成交率 |
| 沉淀可复用的训练资产 | 模板/评分规则/知识库条目数 |
| 规模化培养 | 单批可下发任务数、人均陪练场数 |
| 可考核可追溯 | 学员能力雷达图、历史复盘 |

## 2. 用户角色

| 角色 | 端 | 核心诉求 |
|---|---|---|
| 学员（导购/主播） | 小程序 C 端 | 快速开始陪练、对话自然、结束有明确反馈 |
| 运营/培训师 | Web B 端 | 配置客户人设、评分规则、下发任务、看学员数据 |
| 平台管理员 | Web B 端 | 知识库维护、评分模板治理、组织级配置 |
| AI 客户 | — | 根据人设/情绪/场景自然对话，不硬背稿 |
| AI 教练 | — | 按评分维度打分，引用知识库佐证，不臆造 |

## 3. 功能范围

### 3.1 C 端（小程序）

#### 3.1.1 陪练工作台（首页）
- **今日训练**：展示今日推荐任务/推荐模板，一键进入
- **客户选择**：八类客户人群卡片（见 4.1）
- **自由练习**：自选客户+心理卡+难度+场景，快速开始
- **训练记录**：历史陪练列表、结果复盘
- **新建模板**：保存自己的配置

#### 3.1.2 陪练对话页
- AI 客户按人设开场，可配置"学员先开口/AI 先开口"
- 对话过程中异步感知客户情绪，延迟渲染不阻塞
- 每轮结束异步出教练点评（不影响对话延时）
- 支持中途退出/返回键后恢复上次未完成会话（继续/结束）
- 对话结束自动生成结果报告

#### 3.1.3 结果复盘
- 总分 + 各维度雷达图
- 教练点评（好的地方/待改进）
- 话术引用原文对照

#### 3.1.4 我的任务
- 接收 B 端下发的任务
- 任务冻结参数（学员不可改）
- 任务完成情况

### 3.2 B 端（Web 运营端）

| 模块 | 功能 |
|---|---|
| 陪练模板 | 增删改查、客户人群/心理卡/难度/场景/对话参数全量配置 |
| 场景管理 | 训练场景编排、发布预览 |
| 任务投放 | 选择模板+评分规则，下发到学员，冻结参数 |
| 学员档案 | 学员列表（头像/昵称/训练次数/平均分/最近练习）、能力雷达、历史复盘 |
| 产品知识库 | 产品录入、症状-功效映射、禁忌、产品场景（护肤/保健/母婴/家清等全品类） |
| 评分配置 | 评分维度 CRUD、评分模板、模板与维度多对多组合、权重覆盖 |
| 结果复盘 | 查看学员对话与评分详情 |

## 4. 关键产品设计

### 4.1 客户人群八分类（方案 B：与顶部客户选择融合）
客户人群卡片直接作为 C 端陪练入口主选择，替代旧六卡：

| 类别 | 人群 | 销售特征 |
|---|---|---|
| 小姐姐 | 18-25 学生/职场新人 | 追新追潮、预算有限 |
| 轻熟女 | 26-32 白领 | 重成分效果 |
| 宝妈 | 28-38 家庭决策 | 关注安全性价比 |
| 御姐 | 33-42 高消费 | 品牌意识强、要求高 |
| 大姐 | 40-55 个体户 | 重养生、信熟人 |
| 阿姨 | 50-65 退休 | 时间多、爱聊天 |
| Z世代/精致妈妈/新锐白领/都市蓝领/小镇青年/小镇中老年/资深中产/都市银发 | 八类巨量引擎人群 | 按平台标准标签 |

### 4.2 客户心理卡
犹豫型/比价型/怀疑型/冲动型/专业型/故事型/抱怨型/被动型，各带 skepticismBoost、priceSensitivityBoost。

### 4.3 难度等级
友好型 → 普通型 → 刁钻型 → 难缠型。

### 4.4 产品全品类体系
不只是护肤品，覆盖：
- 日常护肤、问题肌调理
- 保健养生（口服美容/滋补/助眠）
- 母婴儿童
- 洗护沐/家清个护
- 减重塑形

### 4.5 客户关系阶段
陌生潜客 → 新粉 → 礼品粉 → 首单客户 → 老客户，各阶段有不同目标。

### 4.6 信任等级
陌生戒备 → 认识认可 → 专业信任 → 个人信任 → 同盟转介。

## 5. 评分与知识依赖

### 5.1 评分原则
- **多对多组合**：一个评分模板可关联多个维度，一个维度可被多个模板引用
- **权重可覆盖**：任务级可覆盖模板默认权重
- **知识依赖**：评分时引用结构化知识库（产品功效/禁忌/场景）
- **LLM 兜底**：某维度未配置约束时，LLM 据通用能力打分，并标注"该维度暂未配置，按通用能力评分"
- **防幻觉**：LLM 不得编造产品功效，知识库未覆盖时明确说明

### 5.2 异步化
- 客户情绪感知：异步 LLM 判断，延迟渲染，不阻塞对话
- 教练点评：每轮结束异步生成
- 结果报告：对话结束后异步生成，失败可重试，不卡死链路

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 并发 | 支持上万人使用，单用户会话异常不影响全局 |
| 容错 | 会话卡死/报告生成失败有恢复策略，不阻塞他人 |
| 安全 | 密钥走环境变量，不硬编码；学员身份经主站网关校验 |
| 部署 | 后端 Docker 化，前端静态托管，HTTPS 反代 |
| 性能 | 对话主路径延时不被异步任务拖慢 |

---

## 7. 边界与不做
- 不做真人视频陪练（纯文本对话）
- 不做支付/订单闭环（训练用）
- 不做独立登录体系（复用公主购主站登录态）
- 不做实时多人对战
